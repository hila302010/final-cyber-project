Explanation of extracted data

  • Whois, crt.sh, A and PTR Records

    By starting with a domain name, we use these tools together to map out a full profile of the domain's infrastructure and ownership

    crt.sh

    Given a domain name, this tool extracts all associated subdomains. It also provides details like the certificate issuer and the validity period of each subdomain’s SSL certificate.


    A Record

    When given a domain name, this record returns the IP address linked to that domain—essentially telling us where that domain "lives" on the internet.


    WHOIS

    By searching with an IP address (or domain), WHOIS returns registration details such as: Domain name, IP address, Organization name, Country.

  • DKIM, DMARC AND SPF

    Given a domain name, we retrieve the DMARC policy that controls how unauthenticated emails are handled, fetch the DKIM record to verify email integrity, and extract the SPF record, to identify which mail servers are allowed to send on behalf of the domain

    DKIM

    Using the domain name, we query the DNS to fetch the DKIM record. This record contains the public key used to verify that emails from the domain were not altered during delivery. DKIM helps validate the sender and integrity of the message.


    DMARC

    Given a domain name, we resolve its DMARC DNS record, which specifies the domain's email authentication policy. This policy tells mail servers what to do with unauthenticated messages (e.g., reject, quarantine, or allow) and where to send reports.


    SPF

    While querying for DKIM or DMARC, we also check for the SPF record in the domain’s DNS. SPF defines which IP addresses are authorized to send emails on behalf of the domain.

  • NetworksDB, Shodan

    By combining NetworksDB and Shodan, we can map an organization’s network footprint, See what services are exposed, identify vulnerabilities or misconfigurations and understand how a network is structured and where it's located

    NetworksDB

    Given a country name and an organization name, by using NetworksDB-API KEY we got the corresponding IP ranges (CIDR blocks) owned or operated by that organization in that region


    Shodan

    Use the IPs or CIDRs from NetworksDB as input in Shodan, we retrieve detailed data for each IP, using Shodan-API, including: Port numbers, Exposed vulnerabilities, IP address, Organization, Country and city Related domains Hostnames

  • github, google dorking

    Given a domain name, company name and optionally a nickname, we gather a wide range of OSINT data: identify employee or internal system mentions, locate exposed files or credentials, and spot overlooked security weaknesses in publicly available sources

    github

    Given a domain name, we used GITHUB - API which helped us get to important data via Github, like repositories or files mentioning the domain or email pattern, find exposed credentials, employee data, or infrastructure leaks (like passwords, admin)


    google dorking

    Given a domain name, we use crafted search queries to extract sensitive data indexed by Google and also find hidden files, login pages, or exposed internal information related to the domain

  • Social Network Services

    Social platforms (especially linkedin) hold massive amounts of publicly available personal and organizational data. By analyzing these platforms, we can gather: employee names and roles, company structure and affiliations, posts, activities, or mentions of the organization and much more relative data.

    Linkedin

    By entering the company name, we used the Selenium automated technique, and simulate a real user browsing the platform. This allowed us to bypass standard limitations (like lazy-loading and scrolling), automatically extract data from profiles, collect a full list of employees associated with the company and retrieve each person’s job title, department, and location.


Cybersecurity Terms

OSINT

Open Source Intelligence – gathering information from publicly available sources such as websites, social media, forums, and more.


DNS

Domain Name System – translates domain names like google.com into numerical IP addresses that computers use to locate each other.


Domain

A human-readable web address (like example.com) used to access websites, linked to an IP address via DNS.


DNS Records

Entries in the Domain Name System that store data like IP addresses and routing information for domains. Includes A, PTR, MX, and other record types.


A Record

A DNS record that maps a domain name to its corresponding IPv4 address.


DMARC

Domain-based Message Authentication, Reporting & Conformance – helps prevent email spoofing by defining how to handle unauthenticated messages using SPF and DKIM.


DKIM

DomainKeys Identified Mail – adds a digital signature to emails to verify the message hasn't been altered and that it came from the claimed domain.


SPF

Sender Policy Framework – an email validation protocol that specifies which mail servers are allowed to send emails on behalf of a domain.


IP and Net Range

An IP address identifies a device on a network. A net range (e.g., 192.168.0.0/24) is a block of IPs used for organizing and managing networks.


CIDR (Classless Inter-Domain Routing)

CIDR is a method for assigning IP addresses and organizing IP networks. Instead of using traditional IP classes (A, B, C), CIDR uses a format like 192.168.0.0/24 to define a range of IP addresses. The number after the slash (/24) indicates how many bits are fixed for the network part, allowing more flexible and efficient allocation of IP ranges. In OSINT, CIDR ranges are used to scan or map all IPs belonging to an organization.


Dorks

Google Dorks – advanced search queries used to find hidden or vulnerable data on websites through search engines.


Selenium

Selenium is an automation tool that simulates how a human would interact with a web browser. It can be used to automatically open pages, click buttons, fill in forms, and scroll through websites. In OSINT and web scraping, Selenium is especially useful for handling dynamic websites like LinkedIn, where data loads as you scroll. It helps extract data by "browsing" the site just like a real user would.


API (Application Programming Interface)

An API is a set of rules and tools that allows different software systems to communicate with each other. It lets you request specific data from a service (like getting user details from a platform) without using the website itself. APIs are commonly used in OSINT to access structured data quickly, such as searching IP info, domains, or employee records without scraping web pages.


User-Agent

A User-Agent is a string of text sent by a browser or tool to a website to identify itself. It includes information like the browser type, operating system, and device. In OSINT and automation, changing the User-Agent can help disguise automated tools (like Selenium or scripts) as real users, allowing them to avoid detection or access data meant for browsers.

Threat actors can use these emails to send malicious links, fake invoices, or social engineering attacks, leading to breaches, data theft, and financial losses. By mapping a company's IP addresses, attackers can identify exposed servers, misconfigured systems, and outdated devices. IP reconnaissance can lead to vulnerability scanning, unauthorized access attempts, and even full-scale network breaches if weaknesses are found.
Knowing employee names and their roles enables highly customized social engineering attacks. For example, pretending to be a CEO (“CEO fraud”) or an IT support member becomes much easier. It also helps attackers prioritize high-value targets, such as executives or system administrators.
Mapping a company’s domains and subdomains can uncover forgotten, misconfigured, or vulnerable assets (“shadow IT”). Attackers use this information to find weak entry points into the network or to exploit older systems that aren’t properly secured.
These email security records reveal how well a company protects its domains from spoofing and impersonation. Weak or missing DKIM, SPF, or DMARC configurations make it easier for attackers to send fake emails that look legitimate, increasing the success of phishing campaigns.
